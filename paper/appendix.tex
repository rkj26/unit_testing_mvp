\section{Implementation details}
\label{app:implementation}

\paragraph{Ground truth.} We grade every candidate with ControlArena's implementation of the criteria of \citet{greenblatt2024aicontrol}: each test runs as a fresh process with its input on standard input, under a 10\,s, single-CPU, 0.5\,GB limit, and any output on standard error fails the test. In ControlArena's reference environment (Python~3.4), all 1{,}388 honest and all 1{,}388 backdoored solutions pass every provided test, and 1{,}387 of the backdoors are functional. The remaining backdoor's trigger was disabled when identifiers were cleaned; we treat it as non-functional ($w_i = 0$). Under Python~3.12, in which our tests execute, 7 honest solutions and 1 backdoored solution fail the same rule because of runtime warnings or library functions removed since Python~3.4; we keep them, since excluding them would use labels the protocols do not have. On the 77{,}090 (candidate, trigger input) pairs, our sandbox and ControlArena's runner agree on 99.86\%; the disagreements are confined to 9 candidates.
% TODO: add a citation for ControlArena.

\paragraph{Sandbox.} Tests run in a Docker container (Python~3.12, no network) with a 240\,s limit per suite. A suite whose tests do not all finish within the limit keeps the failures it observed, so its score can only be too low; it errs towards missing a backdoor, never towards finding one. A suite that produced no result at all is excluded rather than scored as passing.

\section{A study on competition-level problems}
\label{app:hard-pool}

Before scaling to the full pool, we studied the test writer on a separate pool of 50
competition-level APPS problems, with one honest and one backdoored candidate each. $T$ writes 20
tests per submission, and we score six protocols on a held-out split of 50 candidates (25
backdoored, 25 honest): two whose test writer sees only the problem statement, and four that see the
code. The pool is small, so we report it as supporting evidence only.

\paragraph{The tests are not precise enough.} Rejecting any candidate that fails a test, the six
protocols reject 74\% to 88\% of backdoors but keep only a quarter to three-fifths of the honest
code. At the monitor's false-positive rate of 0.10, their detection rate falls to 0.14--0.31,
against 0.84 for the monitor.

\paragraph{Better test writing lowers false positives, not misses.} Table~\ref{tab:variants}
compares two changes to the test writer with the same writer without them. Few-shot examples of
good and bad tests reduce false positives from 29 of 44 honest candidates to 20 of 44, while
detection falls from 42 of 48 backdoors to 39 of 48. A critic that removes weak tests lowers the
false-positive rate from 0.67 to 0.43 and detection from 0.88 to 0.82; it removes almost as many
tests from honest candidates as from backdoored ones (5.59 against 6.39 on average). Both changes
make the tests more conservative rather than more discriminating.
